# Nova Wake

**Orbital Patrol** — a wave-defense canvas game. Hold the line through incoming enemy waves.

## Play

Open the deployed site and click play. Desktop: mouse / keyboard. Mobile supported.

## Stack

- React 19 + TanStack Router / Start
- Vite + Nitro (Vercel preset)
- Zustand, Tailwind CSS v4, Radix UI
- Canvas 2D game engine

## Local development

```bash
npm install
npm run dev
```

App listens on `http://0.0.0.0:8080`.

## Build

```bash
npm run build
```
